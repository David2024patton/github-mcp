# Public launch security review — October 2026 (PUB-5 part C)

Scope: the free public sign-in (anyone connects their own GitHub account from the website, the directory-less launch in
`docs/pr-cards/PUB-5.md`). Reviewed on `main` after PUB-5 part A and GOD-6; **PUB-5 part B (fair-use limits, cost protection, inactive clean-up) merged
afterwards and its rows (5, 9, 12) were added in a follow-up.** Every
file, function and test below was opened and checked.

Result key: **Proven** = a test exercises the block. **Fixed here** = a gap this review found and closed with a new test.
**Accepted** = a known, low-impact residual risk, recorded on purpose.

## Dependencies

`npm audit --omit=dev` found four items before this PR: `body-parser` (high), `zod` (high), `fast-uri` and `ip-address`
(moderate). `npm audit fix` updated them within their allowed ranges (lock file only); it now reports **0 vulnerabilities**.

## Remaining items

- **Cost rate:** the default estimate (5 cents per 1,000 calls) should be re-measured once real traffic exists.
- **No global cap across all people:** part B limits each person and pauses *new* sign-ups on cost; it does not cap total calls from existing people. Accepted for launch; the cost pause and the owner usage page are the control.
- **Older refresh tokens:** only the previous refresh token ends the sign-in when shown again (row 3).
- **Webhook replay:** accepted (row 4).
- **Default spend cap:** a product decision for Chris (row 6); nothing is blocked on it.
