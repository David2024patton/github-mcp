## Tests

- `tests/unit/fake-github.test.js`: route matching with path parameters (including an encoded `a%20b` file path);
  recorded body and headers; `when(...).reply` with a function; unknown route recorded as unmatched.
- `tests/unit/registry.test.js`: duplicate tool names throw.
- `tests/unit/check-secrets.test.js`: a planted real-shaped `ghs_` token and a PEM block in a temp file fail;
  `ghp_FAKE…` passes.
- `tests/unit/check-core-imports.test.js`: a planted `src/core/x.js` importing `@octokit/core` fails (temp dir).
- `tests/db/contract.test.js`: contract runs on throwaway Postgres.
- `tests/shapes/ping.test.js`: an Octokit instance wired to `fake-github` sends `GET /repos/{owner}/{repo}` with the
  `X-GitHub-Api-Version: 2026-03-10` header set through `request.headers` and receives the fixture.
