## Built (part 1)

`src/github/ci-state.js`: the latest run per check name (matched by app when the rule names one), commit statuses as fallback, "missing / pending / failure / success". With no required check it requires every existing check; zero checks is not green; any failed read gives `green: null` (unknown), never green.
`src/tools/pulls-read.js`: `github_pr_list` (author/label filtered on our side), `github_pr_get` (review decision, unresolved threads, checks at the exact head when open), `github_pr_get_diff`, `github_pr_list_files` (patches cut at 1500), `github_pr_list_commits`.
