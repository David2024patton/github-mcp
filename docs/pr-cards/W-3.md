## Contract

`github_workflow_review_threads({owner?,repo,number,expectedHeadSha?,dispositions?,planKey?,confirm?,dryRun?})`.
Without dispositions: enumerate complete thread inventory (including resolved for recovery),
return unresolved comments marked untrusted, current head context and coverage.
Each disposition: threadId, disposition fixed/already fixed/superseded/answered,
explanation; fixed/already fixed requires provable changed original lines; superseded
requires an outdated thread; answered requires nonempty explanation. Caller judgment
is explicit, never an AI claim that textual change proves semantic correctness.
Missing/capped/binary/moved context is explicit. Missing/capped comparison fails closed.
Preflight all selected rows before writes; stale head/foreign ID/changed discussion
invalidates confirmation. Delegate only wrapped `github_review_reply` and
`github_review_resolve_thread`, with optional exact-head check added to both.
One combined preview then one confirm; no provider writes during preview. Child
journal stores each step. Re-entry uses stable keys; after unknown result stop,
never send a second reply or resolve. Budget returns completed rows and next action.
No new schema, permissions, production activation, spend or account access.
