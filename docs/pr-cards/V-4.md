## Drift check A
| Assumption | Verified on baseline | Decision |
| --- | --- | --- |
| The public-URL boundary can be reused for outbound POSTs | `publicHttpsUrl`, `resolvePublicIpv4` pin the chosen address and refuse private ranges; only GET downloads existed | New `src/dev/forward-sender.js` re-applies the policy at every send, pins the address, refuses redirects and never retries |
| Scratch cleanup tolerates a test webhook | `inspectScratchArtifacts` refused ANY live repository webhook ("V-4 cleanup not verified") and scenario bounds reject non-scenario objects | Accept only hooks recorded by exact ID in the run (type Repository); coverage check now includes webhooks; at most three test webhooks per run are allowed on top of any scenario's bounds |
| Change journal stores `before`/`after` | `claimChange`/`finishChange` persist them | Both hold only host names, counts and booleans — never a URL path, payload or secret |
| Forwarders need a table | none | Additive `dev_forwarders` (cap 20 per account+connection, enforced inside the INSERT) with fake and PostgreSQL contract |
| `webhook-target` seed scenario | plan-only | Unchanged; completing it is V-1 work in the next bundle (it can now rely on `github_dev_create_test_webhook`) |
