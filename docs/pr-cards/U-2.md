## Finite integration and denial checklist
Public tools: github_graphql_read(query, variables, owner?, cred?) [read_only/everyday/full]; github_graphql_write(mutation, variables, owner?, cred?, dryRun?, confirm?, requestKey?) [full].
Use the trusted connection account; U only if explicitly selected and enrolled, I otherwise. No caller-supplied token, header, endpoint or scope override. Parse exactly one operation; validate the full GraphQL document and typed variables against pinned GitHub SDL. Resolve aliases, fragments and inline fragments, refuse second mutation/op and unused mutation payloads, non-declared variable values and nested credential/bypass material. Reject unknown fields, introspection over authority and unsafe cost before provider call.
Estimate GitHub point cost from actual pagination, reject >500 points or >500000 possible nodes (and unbounded connection selection). Curated merge and equivalent bypasses must refuse with specific guarded tool. Unknown mutations default production + access widening and spend-risk unknowns fail closed; owner production/permission guards remain independent.
Mutation preview gets real scoped before-state, describes exact root mutation/target, applies at most once after confirmation, uses readback only when a stable independently queryable object exists; otherwise return unconfirmed, never invent confirmed true. No production activation/real write, costs or cleanup in fixture tests.
Focused GraphQL, registry and security tests while building; complete existing npm check, unit shards, db, shapes, rtc, release-policy on exact head, independent review/merge, honest live acceptance queue, handoff.
