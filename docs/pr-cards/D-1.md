## Drift check A

| Card assumption | Actual | Kind | Correction / test |
|---|---|---|---|
| Read tools can call GitHub | The dispatcher passed `credentials` and the gates only to write tools | semantic (ours) | `credentials` now goes to every handler; gates stay write-only. Covered by every read test |
| `github_repo_delete`/transfer "have no inverse"; rename inverse is the old name | Rename's read-back is at the new name | none | `singleField` reads the new name after a rename; inverse tested through the contract (change-log row) |
| Custom properties take a free-form object | The argument checker supports a JSON Schema subset without free-form objects | semantic (ours) | `set: [{ name, value | values }]` and `remove: [names]` instead of a map |
| Fork lands "in an account" | GitHub forks asynchronously (202) | none | Verified from the 202 body (`fork: true`); the result says files may take a moment |
| `GET /orgs/{org}/repos` and `/users/{username}/repos` accept the same `type` | They accept different values | none | The user list rejects org-only types in plain words |
| Stats endpoints answer 202 while computing | Confirmed in the vendored description | none | Up to three asks (1.5 s, 3 s), then "GitHub is still computing; try again" |
