## Completed coherent source slices

1. **O-1A: Full owner-settings map.** All major repository, organization and personal settings families now have unique IDs, HTTPS navigation URLs, plain-language controls, explicit actions and expected states. The `github_where_is_setting` built-in additionally interpolates verified named account and repository parameters; follow-ups never silently widen connected accounts.
2. **O-1B: Page discovery.** `github_admin_list_guided_settings` searches and paginates all guided settings by scope with preserved expected state and a mandatory manual/provider verification type. No page click is counted as a configuration change.
3. **O-1C: Genuine named readback.** `github_admin_check_setting` verifies current GitHub organization 2FA against the caller's expected value, refuses unrecognized accounts, and reports manual/no-provider-support settings as unverifiable rather than marking them finished.
4. **O-1D: Account and security overview.** `github_admin_overview` reads enrolled-account server production/spend state, org profile/plan/2FA/default grants, owner/member/outside-invitation inventories, bounded repository security flags, Actions token permissions, deploy keys, App installs and token requests. Each check is classified `ok / needs_attention / not_readable / not_available_on_plan`. `github_admin_review_security` turns the same verified signals into prioritized owner security review without making settings changes.
