## Implemented source and contracts

\`src/tools/org-read.js\` provides scoped, bounded, exact enrolled-org reads.
\`src/tools/org-write.js\` provides nine shared confirmed/journalled write
contracts: exact preflight, scope check, provider operation, independent readback,
idempotent request key and refusal on ambiguous partial state. All nine share
the existing MCP/HTTPS/meta dispatch guards; none accepts raw tokens or secrets.
Catalog and registry must remain consistent.

GitHub pinned REST requests include GET/PATCH org, member membership GET/PUT,
member DELETE, invitation list/create/delete, outside collaborator PUT/DELETE,
org user blocks, organization custom-property schema and immutable releases.
Provider reference: https://docs.github.com/en/rest/orgs/members,
https://docs.github.com/en/rest/orgs/custom-properties,
https://docs.github.com/en/rest/orgs/orgs .
