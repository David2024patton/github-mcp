## Drift check A

| Card assumption | Actual | Kind | Correction / test |
|---|---|---|---|
| A spend tool's cost can come from `classify` | `classify` could return any number, including one built from arguments | semantic (ours) | `defineWrite` takes a `price` function; it is **required** when `declarations.spend`, its result replaces any classifier cost, and a throw or a bad number refuses with `refusedBy: 'spend'`. `sampleSeat` moved to `price` |
| The catalog's Safety/Cred/Profile cells are documentation | They are the only complete statement of each tool's safety | none | The checker now fails any registered tool whose declarations disagree with its row, and any tool without a row |

| `github_enable_production` is `C` | It declares `accessWidening` (production connections could then change real repositories) | drift in the catalog | Catalog row now `C·A` |
| Production tools use the `I` credential | They make no GitHub call | drift in the tools | `cred: '—'` declared, as the catalog says |
| Read tools can be checked for credential | Read tools carry no cred declaration (e.g. `github_whoami` lists `I` though it calls nothing) | none | Credential is compared for write tools only |
