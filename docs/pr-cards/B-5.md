## Built

- `src/tools/errors.js`: `describeGithubError` (what happened, likely cause, what to do, one technical line with the request id) for 401, 403 permission (names the permission from `x-accepted-github-permissions`), primary and secondary rate limits (reset in Denver time), 404 (not found or no access, naming the account), 409 (empty repository, conflict, sha mismatch), 422 validation (each field and code), repository rule violations (each rule and ruleset), required checks (which check, its state), base or head branch modified, 451, 5xx and network; `describeGraphqlErrors` (type and partial data); unknown errors fall back to the plain status line.
- `src/tools/util.js`: `shapeResult` (secret fields `[hidden]`, token and key shapes replaced, `_local` Denver times, `_display` dollars, `untrusted: true` by `author_association`, PRODUCTION banner) and `redact`.
- `src/tools/dispatch.js` shapes every result (reads and writes).
- Tests: `errors` (20), `util` (7), `dispatch-shaping` (2), updated `write-core` and `server-tools`.
