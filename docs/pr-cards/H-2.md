## #189 — Observability and privacy-safe delivery reads

Build `src/tools/webhooks-read.js` with `github_webhook_list`, `github_webhook_get` and `github_webhook_list_deliveries`. All calls use the pinned GitHub client, bounded `listAll`, exact hook/delivery identities, and scoped REST routes. No signing values, request headers, path/query components or payload bodies are returned. The caller sees delivery health and whether a payload exists, with an explicit limitation.

Register read schemas and metadata in `src/tools/index.js`, `docs/TOOL-CATALOG.md` and `tests/unit/registry.test.js`. Test `tests/unit/h2-webhooks-read.test.js`: genuine fake GitHub REST shape validation, repo/org scoping, security redaction, exact numeric identities, full raw delivery body never returned. Run `npm run check`, unit, shapes and all exact-head GitHub Actions before merging. Code is never claimed as connected acceptance.
