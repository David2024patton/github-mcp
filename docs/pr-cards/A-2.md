## Build contract

| File | What |
|---|---|
| `src/db.js` | `export const SCHEMA_TABLES` (frozen list of the 13 table names in §2 order); `export const CONNECTION_FIELDS = ['default_account', 'accounts', 'mode', 'profile', 'listing']` and `connectionSettings(row)` (A-3 copies every field on refresh — hub contract §2); `export function createDb(sql = productionSql())` → `{ initSchema(), listTables() }`. `productionSql()` lazily calls `neon(process.env.DATABASE_URL)` and throws the plain message "DATABASE_URL is not configured. Set it in the server environment." — never at import time. `createDb` throws `TypeError` when `sql` is not a function. All SQL is static tagged templates (no string building). `initSchema()` creates exactly the §2 tables and `change_log_request_key` index with `IF NOT EXISTS`, idempotent; no `DROP`, no `ALTER … DROP`, no data rows |
| `test/helpers/fake-db.js` | gains `initSchema()` recording `SCHEMA_TABLES` and `listTables()`; keeps `put/get`; first-line comment updated |
| `docs/ARCHITECTURE.md` | "Database tables" lists the 13 tables and the index as built |

Secrets columns stay ciphertext or hashes only: `*_enc` for credentials, `token_hash`/`refresh_hash` for tokens. No
column may hold a plain token, key or secret.

## Tests

- `tests/db/schema.test.js` (throwaway Postgres): `initSchema()` creates exactly `SCHEMA_TABLES` (compare
  `information_schema.tables` for `current_schema()`); running it twice changes nothing (snapshot of
  `information_schema.columns` + `pg_indexes` equal before/after); defaults — `gh_accounts.credential_kind = 'app'`,
  `installation_status = 'none'`, `production_enabled = false`, `spend_limit_cents = 0`; `oauth_codes`/`oauth_tokens`
  `mode = 'preview'`, `profile = 'everyday'`, `listing = 'catalog'`, `kind = 'connector'`; `change_log_request_key` index
  exists; **no plaintext secret column**: every column whose name contains `token`, `secret`, `key`, `pem`, `refresh` or
  `verifier` ends in `_enc` or `_hash` or is one of the non-secret names `scope_key`, `installation_key`, `request_key`,
  `url_key`, `token_hash`, `refresh_hash` (the test lists the allow-list explicitly).
- `tests/unit/schema.test.js`: fake `initSchema()` twice → same `listTables()`; `createDb('x')` throws `TypeError`;
  `createDb()` without `DATABASE_URL` throws the plain message; importing `src/db.js` with no env does not throw.
- `tests/unit/db-contract.test.js` and `tests/db/contract.test.js` still pass unchanged.
