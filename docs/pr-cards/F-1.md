## Implemented request/guard contract (#167)
- `src/tools/issues-read.js`: `github_issue_list` (bounded refill), `github_issue_get` (optional relationships with availability disclosure), `github_issue_list_comments` and `github_issue_list_timeline`.

## Relationships slice (#170)

Adds `src/tools/issues-relations-write.js` and matching write-contract / ownership tests. Every referenced child or blocker must be independently read from the same repository and bound to its GitHub database ID. Sub-issue reordering only targets independently listed children of the same parent; incomplete lists prevent writes. Add/remove calls carry one provider mutation each and verify the relationship after write. GitHub may disallow certain relationship operations by repository plan; provider denial is surfaced rather than guessed. Full F-1 cannot be marked MERGED until transfer and reactions are built and tested.
