## Implementation and verification

Registry-only composition. Read-only sections retain errors and explicit coverage. Release and deletion use their existing defineWrite contracts. Branch cleanup pins expected SHA and closed PR evidence at the writer boundary; GitHub deletion has no atomic expected-SHA parameter, so nearest-before/readback verification cannot promise an atomic compare-and-delete.

No provider credential, production activation, spending, access changes, external notifications or disposal is authorized by this plan. Actual provider acceptance is separate.

Focused tests: tests/unit/workflows-maintenance.test.js plus affected branch/release contracts. Full publication: npm run check; npm test; npm run test:shapes; exact-head CI database and release-policy.
