## A-5c — built (#13)

- `src/github/webhook.js` (`signatureMatches`, `readRawBody`, `createWebhookHandler`) and `api/github/webhook.js` (body parser off). Verified with HMAC-SHA256 over the exact bytes using `node:crypto` (no `@octokit/webhooks`: one fewer dependency, and only `src/github/client.js` may import `@octokit/*`). The App is found by `X-GitHub-Hook-Installation-Target-ID`; a missing, unknown or mismatching signature answers 401 before anything is read or stored. Handled: `installation` (created, deleted, suspend, unsuspend, new_permissions_accepted), `installation_repositories` (added, removed), `github_app_authorization` (revoked). Every change also drops that installation's cached tokens. An installation on an account that does not own the App is ignored (never stored, so never used). A "deleted" report for an older installation does not clear a newer one.
- `src/tools/server.js`: `github_whoami` and `github_list_accounts` (read-only, `detail` and `fields`, only the accounts the connection may use, credential types as true/false, no last-four characters), `src/tools/dispatch.js` `createReadOnlyDispatch` wired into `api/mcp.js`, `spend_limit_cents` added to `db.listAccounts` (and the fake).
- Tests: `webhook` (11), `server-tools` (9: results scanned for token and key shapes, dispatcher refusals, MCP round trip over HTTP).
