# R-2 — HTTPS tool API, manifest, OpenAPI, shared rate limit

**Status:** MERGED in #225 as part of the R-1/R-2/R-3 bundle (card text for R-1 holds the plan and the evidence).

## What it does (plain words)

The HTTPS door recognises a scoped pass, lists only the tools that pass may use, runs changes through the same guarded write layer as the MCP door (preview, confirm, read-back, change-log number in the answer), keeps `_batch` read-only, and counts requests per pass in PostgreSQL so several server copies share one limit.

## Drift check

Done against `origin/main` 77b921e. Legacy read-only passes keep their exact old behaviour (scratch organization only, server/meta areas). A scoped pass asking for a real tool outside its scope now gets 403 `refused_by_guard`; an unknown name stays 404. The manifest note and OpenAPI mode enum now allow production.
