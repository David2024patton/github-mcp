Private paid security remains owner/provider blocked; production-like envs without specified reviewed policies remain needs_owner_review. - A second run of completed provider state selects no write, returns its draft/doc and actionable outstanding owner review. Interrupted/uncertain writes require provider re-observation; no stage counter invents success.
