## PR #177 — search end-to-end
- `src/tools/search.js` exports `github_search_github`, one unified search tool with type `code|issue|pull_request|commit|repository|user`, query, sort, order, page and max.
- GitHub REST: `GET /search/code`, `GET /search/issues` (with is:issue or is:pr), `GET /search/commits`, `GET /search/repositories`, `GET /search/users`. No provider mutation.
- Bound 50 results/page, search window 1000, return total_count, incomplete_results and more_possible. Search results projected, no raw file blobs, secret-bearing text restricted to short fragments and standard redaction.
- `tests/unit/f3-search.test.js` fake GitHub OpenAPI validates route and arguments for all six logical types, incomplete page metadata, PR/issue filtering and fragment limits.
- Finish criteria: exact head green `ci` and `release-policy`, reviewer conditions, registered expected name and catalog marker. Discussions/Projects follow as independent approved work; F-3 remains IN_PROGRESS.
