## Drift check A

| Card assumption | Actual | Kind | Correction / test |
|---|---|---|---|
| Job and run logs are summarised, never dumped | A job log is a redirect to plain text; a run log is a redirect to a zip; Octokit follows it and returns bytes for the zip | none | `src/github/log-summary.js`: last 400 lines, up to 40 distinct error lines, timestamps and colour codes removed, runs of 200+ base64-looking characters replaced (test: none survive); zips read from the central directory (stored and deflated), 50 MB cap, 2 MB per log file |
| `listAll` pages every list | Workflow, run and job lists wrap items in an object; the paginate plugin fails on them with the fake | semantic (ours) | `listWrapped` pages by page number and stops at `total_count` |
| "Runs waiting for approval" has an endpoint | Only per-run `pending_deployments` exists | none | Lists runs with `status=waiting` (up to 20), then asks each run |
| Failed step log is found by step name | Archive layout is `<job>/<n>_<step>.txt`; older layouts are `<n>_<job>.txt` | none | Both matched; entries for failed steps preferred, otherwise all of the job's entries |

## Drift check A (part 2)

| Card assumption | Actual | Kind | Correction / test |
|---|---|---|---|
| Dispatch is production when the workflow deploys to a production environment | GitHub does not say which environments a workflow uses | semantic (ours) | `src/github/workflow-env.js` reads the `environment:` keys of the workflow file at the ref (inline, block and flow forms); an expression or an unreadable file counts as production (tests) |
| Dispatch returns the run id (G1) | API 2026-03-10 answers 200 with `workflow_run_id` | none | Read back with `GET runs/{id}`; undo cancels that run (test) |
| Force-cancel needs confirm, but the catalog marks cancel as preview-only (P) | The write layer can force confirmation only for the whole tool | semantic (ours) | `apply` refuses `force: true` without `confirm: true` with a plain sentence (test) |
| Workflow inputs are a free-form object | The argument checker has no free-form objects | semantic (ours) | `inputs: [{ name, value }]`, turned into the object GitHub wants (test checks the request body) |
| Rerun is allowed any time | GitHub rejects reruns of runs still going | none | Refused with "wait or cancel first"; the preview and result show the attempt number (test) |
