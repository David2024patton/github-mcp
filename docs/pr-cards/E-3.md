## Drift check A (part 2)

| Card assumption | Actual | Kind | Correction / test |
|---|---|---|---|
| "App cannot approve PRs it opened" is detected before sending | An installation token cannot ask GitHub who it is, so the server cannot know the PR is its own | semantic (ours) | GitHub's 422 is turned into a plain sentence (test); nothing is guessed |
| Resolving an already resolved thread is `confirmed: true` with no write | `defineWrite` has no built-in no-op | none | `apply` skips the mutation when the thread is already in the wanted state; read-back confirms (test: no mutation sent) |

## Built (part 2)
