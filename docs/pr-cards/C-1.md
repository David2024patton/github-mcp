## Built

- `src/core/result-rules.js` (service-agnostic): `projectFields`, `capText`, `fitToBudget`, `describeBody`, `listKeyOf`, `pageOfBody`, `RULES` (4,000 characters, 400 log lines, 8 KB, 20 per page, 100 max).
- `src/tools/summaries.js`: 29 summary mappers (repository … codespace). `src/tools/define-read.js`: `defineRead`.
- `src/tools/dispatch.js`: read replies go summary → shape → fields → keep → cap → fit; anything cut gets a `kept_result` note with a `res_…` handle.
- `src/db.js`: table `result_store` (16th table), `putResult`, `getResult` (same connection only, 24 hours). Contract test on the fake and Postgres.
- `github_get_result` (catalog row built).
- Tests: `result-rules`, `summaries` (every type), `read-pipeline`, `annotations`, `result-store` (unit and database).
