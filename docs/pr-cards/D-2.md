## Drift check A

| Card assumption | Actual | Kind | Correction / test |
|---|---|---|---|
| `github_content_get` returns text up to C4's cap with a handle | The result rules cut long text at 4,000 characters and keep the whole result behind a handle | none | Test: 25,000-character file gives `kept_result.handle`; binary files (NUL bytes) return size and link only; files over 1 MB or without base64 content say so |
| Path with spaces/`#` is encoded | Octokit encodes path parameters (including `/` as `%2F`) | none | Test: the request path contains no raw space or `#` and decodes to the original |
| Archive link is the redirect only | `request: { redirect: 'manual' }` returns GitHub's 302 and its `location` header | none | Test with a fake 302; the guidance says the link is short-lived and may carry a temporary access code, so it is not stored |
| `src/**/*.js` matches `src/a.js` | The shared glob needs a folder between the slashes | semantic (ours) | The tree tool also tries the pattern with `**/` removed; the shared glob (used for production names) is unchanged |
| `github_content_check_codeowners` says "no CODEOWNERS file" on 404 | GitHub answers 404 for both a missing file and an unknown repository | none | Reported as `no_codeowners_file: true, problems: null` with a note that this is not "no errors" |

## Drift check A (part 2)

| Card assumption | Actual | Kind | Correction / test |
|---|---|---|---|
| "File changed between preview and confirm refused" | Preview and confirm are separate calls; nothing carries the preview's version | semantic (ours) | The preview shows the version (sha); `expectedSha` / `expectedHeadOid` make the second call refuse a different current version, naming the new one. Without it the current version is used, and GitHub itself rejects a stale sha |
| `github_git_update_ref` shows commits dropped | The compare endpoint gives `ahead_by` of the current head over the new target | none | `ahead_by` = commits the branch has that the target does not; non-zero needs `force: true` |
| Undo of an update restores the previous content (audit G17) | The contents API returns the previous content with the version | none | Inverse is `github_content_put_file` with the previous base64 content, or `github_content_delete_file` when the file did not exist (tested) |
