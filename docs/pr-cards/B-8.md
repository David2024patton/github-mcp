## Drift check A

| Card assumption | Actual | Kind | Correction / test |
|---|---|---|---|
| A connection list can show "last used" | No column was updated on use | none (column existed) | `getAccessToken` touches `last_used_at` at most once a minute; a failure never fails the request |
| `github_list_connections` shows all connector logins | A read-only connector would learn about logins for accounts it cannot use | semantic (ours) | Only logins that share an account with the caller are listed; a login that also reaches other accounts is shown with `can_revoke_here: false` and cannot be switched off from here |
| Passes appear in the list | Passes do not exist until Batch R | none | The result says so; they will join the same list |
| `github_recent_changes` reads the change log | It could show other accounts' changes | semantic (ours) | The query is limited to the caller's accounts; an `account` outside them is refused |
| `github_set_default_account` changes "the" default | The default is per connector login, stored on its live tokens | none | Changes this login only (`setConnectionDefaultAccount`), verified by reading it back |
