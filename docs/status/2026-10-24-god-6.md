# 2026-10-24 — GOD-6 "Act as me"

**What now works (in plain words):** when you have added your master token, your assistant's changes on GitHub are made
with *your* GitHub login, so GitHub shows you — not the Robinson app — as the one who did it. The app still makes the few
things only an app can do (check runs and similar), everything for read-only connections and service passes, and any change
to a branch that has rules. If your token expires or GitHub rejects it, calls quietly go back to the app; a rejected change is
never sent twice. Every result says who acted (`acting_as`), `github_whoami` shows it, and the change log records it.
A switch on My connection turns Act as me off (on by default once a master token is added).

**Skipping branch rules on purpose:** as you asked, an owner or admin can say `overrideRules: true` with a reason. The preview
lists exactly which rules would be skipped, you confirm, it is sent as you, and GitHub itself decides whether you may. A second
switch on My connection ("Allow overriding branch rules") turns this off. Agents building this project never use it on your
real repositories.

**What this means for you:** any check that only accepts you (for example appliance-desk's extra testing build) will also
accept an agent using your God-mode connection, because GitHub sees you.
