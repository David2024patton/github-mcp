# 2026-10-23 — GOD-2 + GOD-3 (master token for personal-account tools; what it unlocks)

**In progress** (one PR from branch `ai/claude/god-2-3-20261023`; head SHA and CI state are on the PR).

- GOD-2: the ~25 tools that act on your own GitHub account (gists, SSH/GPG/signing keys, emails, profile, blocks,
  invitations, follow, watch, star, star lists, social links, status, your Codespaces, organization migrations) now use
  your master token when you added one and it carries the right permission. Without one, or on a read-only connection or
  a pass, they work exactly as before. Code: `src/github/personal-cred.js`.
- GOD-3: `github_whoami` and the My connection page list each God-mode area as unlocked or locked (and which permission to
  tick on GitHub to unlock it). The master-token page has a second link that adds the optional enterprise permissions.
  Code: `src/github/master-areas.js`.
- Checked by: `tests/unit/god-2-personal-cred.test.js`, `god-2-call-sites.test.js`, `god-3-master-areas.test.js`,
  the whoami case in `server-tools.test.js`, the My connection case in `tests/db/pub-6-public-connect.test.js` and
  `tests/browser/sign-in.test.js` (the last two run in CI; no local Postgres here).
