# 2026-10-24 — INV-1: credential inventory finished

**Result.** The capability report now shows 0 unresolved conflicts (was 65) and every REST operation has at least one credential type decided
from official evidence. Nothing was guessed: where GitHub's two sources disagree and neither is stronger, the answer stays "unknown" with the
reason written on the row.

**How.** GitHub publishes, per operation, which token types may call it. That list is vendored (small file, pinned to a GitHub commit) and read by
`src/github/credential-derivation.js`, together with each operation's own text for classic-token scopes and App-JWT-only operations.
Hand-reviewed rows win; a test shows the new decisions never contradict them.

**Honest limits.** This records what GitHub *documents*, not what a connection can do (that still needs real-account evidence, ACC-1). GraphQL
fields are left unknown (no field-level evidence exists). 7,286 individual credential cells remain unknown, each with a reason.
