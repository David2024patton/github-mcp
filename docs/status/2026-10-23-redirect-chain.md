# 2026-10-23 — "Loading bar, then nothing": the last hop back to the app was blocked by the browser

Server records for a real phone sign-in showed everything worked (GitHub sign-in, accounts found, code issued) but the app never collected the code (no token request arrived). Cause: the sign-in page's rules (`form-action 'self' https://github.com`) apply to the whole redirect chain that starts at the form button. When GitHub signs the person in silently, that chain is button → GitHub → our callback → the app's address, and Chrome refuses the last hop because the app's site is not in the list. A run that went through GitHub's install screen worked only because the person's own tap broke the chain.
Fix: the final hand-back (after sign-in, and from the accounts / extra-keys page) is now a small 200 page ("You are connected, returning to <app>…") that sends the person on with a refresh and a Continue link, ending the chain. Also fixed: the "this page was already used" page tried to answer twice.
