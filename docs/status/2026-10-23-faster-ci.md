# 2026-10-23 — faster CI

Measured first: a full CI run already takes about 2¼ minutes (jobs run side by side; longest were unit at ~2 min and
the browser job at ~2 min). Two changes:
- Documentation-only pull requests: each heavy job (unit, db, shapes, rtc, browser) runs `scripts/ci-scope.mjs` first and
  skips its remaining steps when every changed file is Markdown that no test reads (the script greps the test folders
  for each changed file name, so the rule maintains itself). `check` always runs in full; pushes to main always run all.
- Unit tests split into three shards instead of two.
Tests: `scripts/ci-scope.test.mjs` (rules + every timed job has the gated scope step), in `npm run check:session`.
